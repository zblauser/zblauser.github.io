6.3 Design Rules

  • One file where one file will do
  • No runtime the user has to install first
  • Read the spec before trusting the wrapper
  • If the tool needs a tutorial, the tool is wrong
  • Tolerances matter. The aerospace habit transfers
  • Vendor the dependency or do without it
