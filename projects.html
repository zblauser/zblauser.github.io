HAKO

Modal Text Editor

Lightweight terminal-based text editor written in C with vim-inspired modal editing, syntax highlighting, line navigation, and .hakorc configuration. Built for performance and portability across Unix-like systems.

Current version: v0.0.7

Features:

  • Modal editing (normal, insert, visual modes)
  • Syntax highlighting
  • Line jump navigation
  • Customizable via .hakorc
  • Colon command parsing

Planned: LLM integration for in-editor AI assistance

Tech: C, Terminal UI, Portable POSIX

LOMUX

FFmpeg GUI Frontend

User-friendly graphical interface for FFmpeg that simplifies batch encoding, codec flag management, and format presets. Designed for quick launch and intuitive interaction with cross-platform support.

Features:

  • Batch video encoding
  • Codec preset management
  • Format conversion
  • Cross-platform (Windows, Linux, macOS)

Tech: Python, Tkinter, FFmpeg
