3.0 General Description

Software engineer in Tampa. I build tools, mostly for myself, sometimes for other people.

Before software I worked in manufacturing, on parts where tolerances mattered and mistakes cost. That instinct came with me.

The work I like sits where hardware meets software: embedded, infrastructure, anything close to the metal. C when I want to know what's happening. Zig increasingly, for the same reason with fewer apologies. The AI coding wave is pushing everyone toward typed languages anyway; that part I don't mind.
