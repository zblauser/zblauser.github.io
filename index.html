  • Systems programming in C and Zig. Own loaders, kernels, tokenizers
  • Single-file tools. No node, no python, no runtime to install
  • Infrastructure automation and developer tooling
  • Embedded and close to the metal. The hardware/software boundary
  • M.S. Computer Science; B.S. Computer Science; B.A. Political Science
  • Operating location: Tampa, Florida
  • Model agnostic tooling across 13 providers, plus local inference

1.1 General Description

ZB-1 is a systems programmer optimized for low-level work: language runtimes, terminal software, and the infrastructure underneath both. Primary output is small, fast, dependency-free tools: a C inference engine with its own loader and tokenizer, a terminal agent in a single C file, a Zig music client that needs no authentication.

Full specifications for each part are given in Section 2.0. Current operating conditions are given in Section 4.0.
